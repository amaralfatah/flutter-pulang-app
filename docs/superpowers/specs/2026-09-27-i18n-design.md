# Desain Lokalisasi (i18n): Indonesia & English

Tanggal: 2026-09-27
Status: disetujui, siap dibuat rencana implementasi

## Latar belakang

Semua teks UI Pulang saat ini ditulis langsung (hardcode) dalam bahasa Indonesia:
literal `Text('...')` di tiap layar, `PrayerName.displayName` di model, dan judul/isi
notifikasi di `NotificationService`. Format tanggal memakai `DateFormat(..., 'id_ID')`
di sekitar 12 tempat, dan `main.dart` hanya memanggil
`initializeDateFormatting('id_ID', null)`. Belum ada `flutter_localizations`.

## Tujuan

- App tersedia dalam bahasa Indonesia dan English.
- Bahasa default mengikuti bahasa perangkat; user bisa menimpanya di Pengaturan.
- Menambah bahasa ketiga nanti cukup dengan menambah satu file ARB.

## Di luar cakupan

- Menerjemahkan teks bebas / konten dari API (nama kota tetap apa adanya).
- Langkah pilih bahasa di onboarding.
- Arah teks RTL.

## Keputusan

| Hal | Keputusan |
|---|---|
| Sumber bahasa | Ikut sistem, bisa di-override: `system` / `id` / `en` |
| Fallback | Bahasa perangkat selain id/en → Indonesia |
| Istilah ibadah (EN) | Transliterasi umum: Fajr, Dhuhr, Asr, Maghrib, Isha; "Qadha"; "Qibla" |
| Mekanisme | `flutter gen-l10n` resmi (ARB + `AppLocalizations`), tanpa dependency pihak ketiga |
| Template ARB | `app_id.arb` (teks yang sudah ada jadi sumber) |

Pendekatan lain yang dipertimbangkan: `easy_localization` (key berupa string, tidak
type-safe), `slang` (type-safe tetapi butuh build_runner), dan map Dart manual (tanpa
plural ICU, typo key baru ketahuan saat runtime). `gen-l10n` dipilih karena resmi,
type-safe, dan memakai `intl` yang sudah ada.

## Arsitektur

### Setting bahasa

- `SettingsState.languageCode: String` bernilai `'system' | 'id' | 'en'`, default
  `'system'`. Disimpan lewat `PreferencesService` (SharedPreferences), mengikuti pola
  `themeMode`.
- `SettingsNotifier.setLanguage(String code)` menyimpan nilai dan memperbarui state.

### Resolusi locale

- `localeProvider` mengubah `languageCode` menjadi `Locale?`: `'system'` → `null`
  (Flutter memakai locale perangkat), selainnya → `Locale(code)`.
- `MaterialApp.router` diberi:
  - `locale: ref.watch(localeProvider)`
  - `supportedLocales: AppLocalizations.supportedLocales` (id, en)
  - `localizationsDelegates: AppLocalizations.localizationsDelegates`
  - `localeResolutionCallback`: cocokkan berdasarkan `languageCode`; jika tidak ada
    yang cocok, kembalikan `Locale('id')`.
  - `onGenerateTitle: (context) => context.l10n.appTitle` menggantikan `title` statis.
- Ganti bahasa berlaku seketika tanpa restart, karena `MaterialApp` rebuild dari
  provider.

### Format tanggal

- `main.dart` memanggil `initializeDateFormatting()` tanpa argumen locale sehingga
  data id dan en tersedia.
- Semua `DateFormat(pattern, 'id_ID')` diganti memakai locale aktif lewat helper
  `context.localeTag` (dari `Localizations.localeOf(context).toLanguageTag()`).
- `TableCalendar(locale: ...)` di `calendar_view.dart` juga memakai `context.localeTag`.

### Teks di luar widget (notifikasi, isolate background)

- Setiap kali locale ter-resolve berubah (termasuk saat start), app menyimpan
  `resolvedLanguageCode` (`'id'` atau `'en'`) ke SharedPreferences.
- `NotificationService`, yang juga berjalan di isolate AlarmManager tanpa
  `BuildContext`, membaca nilai tersebut lalu memanggil
  `lookupAppLocalizations(Locale(code))` untuk judul/isi notifikasi dan nama/deskripsi
  channel. Nilai kosong → `'id'`.
- Saat bahasa berganti, notifikasi hari ini dijadwalkan ulang agar teksnya ikut
  berganti.
- Catatan: nama channel Android yang sudah dibuat hanya ikut berubah saat channel
  dibuat ulang atau diperbarui; ini diterima, tidak perlu migrasi channel.

### Model

- `PrayerName.displayName` dihapus. Penggantinya extension
  `String label(AppLocalizations l10n)` yang memanggil `l10n.prayerName(name)`.
- Nilai enum dan nilai yang disimpan di DB tidak berubah.

## UI pilihan bahasa

- Di section Tampilan pada `settings_screen.dart`, tambah `ListTile` "Bahasa"
  di bawah Tema, dengan subtitle bahasa aktif.
- Tap membuka dialog `RadioGroup<String>` + `RadioListTile`, mengikuti dialog tema
  yang sudah ada. Opsi: "Ikuti sistem" (diterjemahkan), "Bahasa Indonesia",
  "English". Nama bahasa selalu ditulis dalam bahasanya sendiri supaya user yang
  salah pilih tetap bisa kembali.

## Struktur ARB dan konvensi key

- `l10n.yaml` di root proyek:
  ```yaml
  arb-dir: lib/l10n
  template-arb-file: app_id.arb
  output-localization-file: app_localizations.dart
  output-class: AppLocalizations
  nullable-getter: false
  ```
- `pubspec.yaml`: tambah `flutter_localizations: sdk: flutter` dan
  `flutter: generate: true`.
- File: `lib/l10n/app_id.arb`, `lib/l10n/app_en.arb`.
- Key camelCase dengan prefiks layar: `home…`, `history…`, `qadha…`, `qibla…`,
  `settings…`, `onboarding…`, `notification…`. Teks yang dipakai lintas layar memakai
  prefiks `common…` (`commonCancel`, `commonSave`, `commonSkip`).
- Placeholder dan plural memakai ICU. Contoh:
  - `onboardingCitySearchHint`: `"Cari nama kota (min. {count} huruf)"`
  - `qadhaDebtCount`: `"{count, plural, =0{…} other{…}}"`
  - `prayerName`: `"{name, select, subuh{Subuh} dzuhur{Dzuhur} ashar{Ashar} maghrib{Maghrib} isya{Isya} other{}}"`;
    versi EN: Fajr, Dhuhr, Asr, Maghrib, Isha.
- Akses di widget: getter `context.l10n` ditambahkan di
  `lib/app/extensions/context_extensions.dart`.

## Migrasi string

Dikerjakan per layar, satu commit per langkah. Karena Indonesia adalah template,
teks untuk user bahasa Indonesia tidak berubah di setiap langkah.

1. Fondasi: `l10n.yaml`, ARB awal, delegates di `MaterialApp`, setting bahasa,
   `localeProvider`, `context.l10n`, `context.localeTag`.
2. Onboarding
3. Home (termasuk `prayer_timer_card`)
4. History (`history_screen`, `calendar_view`, `statistics_view`)
5. Qadha
6. Qibla
7. Settings (termasuk UI pilihan bahasa)
8. Widget shared dan nav bar
9. Model (`PrayerName`) dan notifikasi

Yang tidak diterjemahkan:

- Nama kota dari API.
- Pesan `debugPrint`.
- Nilai enum/DB.
- Nama folder dan file backup di Google Drive, supaya backup lama tetap ditemukan.

Teks yang ditampilkan ke user tetapi berasal dari service dipindahkan ke layer UI:
service melempar error bertipe, UI yang memilih teksnya.

## Testing

- `test/l10n/arb_parity_test.dart`: memuat kedua ARB, memastikan himpunan key sama
  dan placeholder tiap key cocok.
- Helper `pumpLocalized(tester, widget, {Locale locale})` yang memasang delegates.
  `widget_test.dart` dan `prayer_timer_card_test.dart` dipindahkan ke helper ini.
- Test resolusi locale:
  - `system` + perangkat `fr` → Indonesia
  - `system` + perangkat `en_US` → English
  - override `en` + perangkat `id` → English
- Test notifikasi: `lookupAppLocalizations(Locale('en'))` menghasilkan judul dan isi
  notifikasi berbahasa Inggris dengan nama solat hasil transliterasi.
- Manual: `flutter analyze` bersih; cek visual kedua bahasa, terutama kemungkinan
  overflow teks EN di kartu home dan grid.

## Kriteria selesai

- Tidak ada lagi teks UI hardcode di `lib/` di luar ARB (kecuali daftar pengecualian
  di atas).
- Mengganti bahasa di Pengaturan langsung mengubah seluruh UI, format tanggal, dan
  notifikasi berikutnya.
- Semua test lulus dan `flutter analyze` bersih.
