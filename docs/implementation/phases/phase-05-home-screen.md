# Phase 5: Home Screen & Check-In

## Tujuan
Implementasi layar utama dengan fitur check-in solat.

## Deliverables

### 5.1 Home Screen Layout
- Header: nama app, lokasi, tanggal
- Info solat berikutnya + countdown
- Progress hari ini (X/5)
- Streak counter

### 5.2 Prayer List Widget
- 5 item untuk setiap waktu solat
- Visual status: belum/sudah/terlewat
- Waktu jadwal dari API
- Waktu check-in jika sudah

### 5.3 Check-In Functionality
- Tap untuk check-in
- Auto-determine status (on_time/late berdasarkan waktu)
- Konfirmasi dialog (opsional)
- Animasi feedback saat check-in

### 5.4 Edit/Undo Check-In
- Long press untuk edit
- Ability to mark as missed
- Hapus check-in jika salah

## Kriteria Selesai
- [x] Home screen tampil dengan benar
- [x] Check-in berfungsi dan tersimpan
- [x] Status auto-calculated
- [x] Edit/undo berfungsi
