# Phase 6: Statistics Screen

## Tujuan
Implementasi layar statistik untuk tracking konsistensi solat.

## Deliverables

### 6.1 Statistics Screen Layout
- Weekly progress bar/chart
- Monthly calendar view (opsional)
- Summary cards (streak, total, average)

### 6.2 Weekly Statistics
- Persentase konsistensi minggu ini
- Breakdown per waktu solat
- Comparison dengan minggu lalu (opsional)

### 6.3 Streak Counter
- Current streak (hari berturut-turut 5/5)
- Longest streak ever
- Reset streak logic kalau miss 1 hari

### 6.4 Monthly Overview (Opsional)
- Calendar heatmap
- Warna berbeda untuk 5/5, 4/5, 3/5, dll
- Tap untuk lihat detail hari tertentu

## Kriteria Selesai
- [x] Statistics screen tampil dengan benar
- [x] Data akurat sesuai database
- [x] Streak calculation benar
- [x] Visual menarik dan informatif
