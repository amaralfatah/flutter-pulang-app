# Phase 4: Riverpod Providers

## Tujuan
Setup state management dengan Riverpod untuk mengelola data aplikasi.

## Deliverables

### 4.1 Prayer Provider
- Provider untuk list prayers hari ini
- Provider untuk check-in solat
- Provider untuk edit/delete prayer entry
- Provider untuk prayer status (on_time, late, missed)

### 4.2 Prayer Times Provider
- Provider untuk jadwal solat hari ini
- Provider untuk solat berikutnya + countdown
- Auto-refresh saat ganti hari

### 4.3 Settings Provider
- Provider untuk user settings
- City selection state
- Notification preferences

### 4.4 Statistics Provider
- Provider untuk hitung streak
- Provider untuk weekly/monthly stats
- Provider untuk total prayers count

## Kriteria Selesai
- [x] Semua providers berfungsi
- [x] State updates correctly saat data berubah
- [x] Providers terintegrasi dengan services
