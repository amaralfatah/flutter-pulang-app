# Phase 8: Settings Screen

## Tujuan
Implementasi layar pengaturan aplikasi.

## Deliverables

### 8.1 Settings Screen Layout
- Grouped settings (Lokasi, Notifikasi, Backup, Tentang)
- Clean list tile design
- Toggle switches untuk on/off settings

### 8.2 Location Settings
- Current city display
- Change city button → city search dialog
- Save to SharedPreferences

### 8.3 Notification Settings
- Master toggle on/off
- Per-waktu toggle (opsional)
- Sound selection (opsional)
- Link ke Android Settings jika permission denied

### 8.4 App Info
- Version number
- Developer info (opsional)
- Privacy note
- Reset data option (dengan konfirmasi!)
